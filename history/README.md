was before it was changed, why it changed, and enough detail to put it back.

Each entry is dated `YYYY-MM-DD-<what-changed>.md`, with any accompanying screenshots
in the same folder under the same date prefix.

This folder is documentation only. Nothing here is served by the live site or
referenced by any page.
